# App icon

`AppIcon.png` is the first imagegen variant selected by the user on 5 September 2026. Generated with the built-in image generator. It depicts overlapping emerald photo frames on a dark rounded tile. The build script creates the standard macOS icon sizes with `sips` and packages them into `AppIcon.icns` using `iconutil`.
