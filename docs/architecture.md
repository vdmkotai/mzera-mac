# Архитектура версии 0.1

Основной стек принят пользователем 5 сентября 2026 года. Rust + GPUI остаётся альтернативой для будущего пересмотра, если результат не устроит. Linux-репозиторий не изменён.

## Модули

| Модуль | Ответственность |
|---|---|
| AppController | Окно, команды, состояние выбора, поколения сканирования и сортировки |
| Scanner / GridLayout | Обход локального дерева и вычисление видимых плиток/секций |
| Catalog | Снимки коллекций SQLite, учёт и вытеснение дискового кэша |
| MediaCache / ImageDecoder | Ограниченные очереди, Image I/O, готовые Metal-текстуры |
| RenderView | Только видимые плитки либо текущий кадр, масштаб и положение |
| Playback | Время кадров, отмена, ограниченная доставка, звук и анимации |
| CMedia | Контейнеры FFmpeg, декодеры, VideoToolbox, конвертация аудио/программных кадров |

## Основные пути

При повторном открытии каталог читается из SQLite, затем сверяется с диском. Каталог сохраняет полный порядок записей и ключ сортировки/группировки: при совпадении ключа повторный показ не ждёт сортировки. Фильтр применяется после сортировки, поэтому сохранённый каталог всегда содержит все файлы. Первый обход выдаёт пакеты по 256 записей через канал максимум с тремя необработанными пакетами. В нём нет декодирования изображений. Полная сортировка выполняется отдельно от UI. FSEvents объединяется с задержкой, затем запускается сверка; пропуски событий не считаются достоверной историей изменений.

Первое наполнение показывает порядок обнаружения до завершения сортировки. При смене сортировки сохраняется выбранный путь. Рекурсивный обход включает `.app`, поскольку в тестовой коллекции внутри них есть игровые изображения. Directory symlinks не обходятся, поэтому цикл ссылок не размножает записи.

Текстуры готовятся в фоновых потоках: Image I/O создаёт уменьшенное изображение с учётом ориентации, затем CGContext принудительно декодирует и приводит его к sRGB BGRA. После этого создаётся общая CPU/GPU-текстура Metal. Обработчик перехода использует готовую текстуру или доступную миниатюру.

Запросы объединяются по пути, размеру/дате изменения и целевому разрешению. Завершившийся старый запрос не попадает в кэш, если его больше нет в текущем наборе. Результат, не помещающийся в бюджет, помечается как отклонённый вместо бесконечного повторного декодирования.

Кадр сетки зависит от числа видимых плиток. Секции пересобираются при изменении коллекции или группировки; изменение ширины пересчитывает геометрию по готовым секциям. Нет отдельных NSView на каждый файл. Шейдеры готовятся во время сборки приложения.

## Видео и время жизни

FFmpeg получает только локальные файлы. Для VideoToolbox регистрируется дополнительный декодер VP9. Совместимые NV12 CVPixelBuffer передаются в Metal через CVMetalTextureCache; программные кадры конвертируются в BGRA. Pixel buffer и обёртки текстур удерживаются до завершения команды GPU.

PCM-аудио преобразуется в planar float stereo 48 kHz и поступает в AVAudioPlayerNode. Видео следует отметкам времени. Накопившиеся поздние видеокадры пропускаются. Воспроизведение имеет отдельный последовательный поток; предыдущий файл отменяется перед запуском следующего.

Доставка кадров на главный поток ограничена двумя слотами. Владение слотом оформлено объектом FramePermit: даже отмена между получением слота и отправкой callback освобождает его. Это закрывает обнаруженный при ручной проверке сбой переключения анимаций.

Поле `hardwareFrames` диагностического CLI учитывает кадры в формате VideoToolbox. Для проверенных H.264 и VP9 путь FFmpeg 9 запрашивает обязательный аппаратный декодер. Не следует обобщать это на все кодеки: для некоторых, включая HEVC, FFmpeg разрешает иной режим. Основание: [FFmpeg 9.0.1, videotoolbox.c](https://github.com/FFmpeg/FFmpeg/blob/n9.0.1/libavcodec/videotoolbox.c).

## Границы первой версии

Сверка по FSEvents пока пересканирует выбранный корень целиком в фоне. Дисковые миниатюры используют PNG; выбор более быстрого формата и кэш экранных копий требуют отдельного сравнения декодеров. Звук, loop и seek реализованы, но длительная проверка синхронизации на разнообразных роликах ещё нужна. Большие RAW/HDR, управление файлами и публикация не входят в эту версию.
