# Mzera for Mac

Минималистичный просмотрщик локальных изображений и коротких видео для Apple Silicon. Swift, AppKit, собственная Metal-сетка, Image I/O и FFmpeg / VideoToolbox. Исходная Linux-версия находится в отдельном репозитории `vdmkotai/mzera`.

## Запуск

Готовое приложение: `dist/Mzera.app`. Сборка содержит необходимые видеобиблиотеки и заранее скомпилированные Metal-шейдеры. Для запуска Homebrew не нужен.

Текущая сборка требует Apple Silicon и macOS 26 или новее. Требование macOS 26 связано в том числе с используемой сборкой FFmpeg. Проверена на M5 Pro с 64 ГБ RAM. Подпись локальная ad hoc; публикации и notarization нет.

```sh
open dist/Mzera.app
open dist/Mzera.app --args --folder "$HOME/Pictures"
```

При обычном запуске восстанавливаются папка, выбранный файл, режим и положение галереи. Приложение читает оригиналы и не предоставляет удаления, переименования или редактирования.

Папку можно перетащить из Finder в любую часть содержимого окна: сетку, просмотрщик, панель управления или строку состояния. Принимается одна локальная папка за раз. Она открывается тем же фоновым загрузчиком, что и через Open; файлы не копируются и не перемещаются. Курсор с плюсом означает, что папку можно отпустить.

## Возможности

- Рекурсивный обход, включая содержимое пакетов `.app`. Символические ссылки не обходятся.
- Общая сетка и группировка по папкам с закреплёнными заголовками.
- Сортировки: папка/имя, имя, дата изменения, размер; фильтр фото/видео.
- JPEG/JFIF, JPEG 2000, PNG, WebP, AVIF, GIF, HEIC/HEIF, TIFF, BMP, APNG, JXL через доступные системные декодеры. Поддержка конкретного профиля зависит от Image I/O.
- GIF, анимированный WebP и APNG воспроизводятся только в просмотрщике. WebP декодируется последовательно через libwebp, APNG через FFmpeg. В сетке все миниатюры статичны.
- WebM, MP4, MOV, MKV, AVI, MPEG, 3GP, WMV, FLV, TS и OGV через FFmpeg. VideoToolbox используется при успешной аппаратной инициализации; доступен программный путь.
- Ролики запускаются без звука и повторяются. Звук включается кнопкой или клавишей V.
- Ручное листание, fit, масштабирование, перемещение картинки, полноэкранный режим. Автоматического слайдшоу нет.
- Постоянный каталог SQLite, дисковые миниатюры, сверка после файловых событий FSEvents.

## Управление

| Клавиша | Действие |
|---|---|
| O | Открыть папку |
| G / C / Enter | Переключить сетку и просмотрщик |
| Esc | Выйти из полного экрана; следующее нажатие вернёт в сетку |
| T | Скрыть/показать панели в обычном окне |
| M | Общая сетка / группировка по папкам |
| Стрелки | Выбор или переход между файлами |
| Option ← / → | Первый / последний файл |
| Option ↑ / ↓ | Страница сетки / скачок на 10 файлов в просмотрщике |
| F | Полный экран без панелей на фоне #000000 |
| W | Переключить вписывание и 1:1 |
| 0 / 1 | Вписать / показать пиксели декодированного изображения 1:1 |
| Pinch / ⌘колесо | Изменить масштаб |
| Перетаскивание | Переместить увеличенное изображение |
| + / − | Масштаб в просмотрщике / размер миниатюр в сетке |
| Space / Shift+Space | Пауза анимации или видео; следующее / предыдущее статичное фото |
| V | Включить/выключить звук |
| Shift ← / → | Перемотать ролик на 5 секунд |
| H / ? | Открыть справку |
| ⌘R | Пересканировать папку |

Основные буквенные команды работают без Command, в том числе при русской раскладке по той же физической клавише. Старые сочетания ⌘O, ⌘F, ⌘G остаются дополнительными. Fn со стрелками также заменяет Home/End/Page Up/Page Down на MacBook.

F открывает выбранное фото/видео на всём текущем экране. Панели, заголовок окна, Dock и строка меню скрыты; фон имеет RGB 0/0/0. Переход выполняется без анимации переключения Spaces. Повторное F или Esc возвращает обычное окно с прежним размером. В полном экране отключена системная тень окна, чтобы у края не оставался светлый контур. T в полном экране не включает панели. Фон не изменяет яркость пикселей самого изображения.

При быстром удержании стрелки позиция учитывает все нажатия, а экран показывает актуальное состояние. Обязательного показа каждого промежуточного файла нет.

## Ограничение работы и памяти

В очереди находятся только видимая область и небольшой запас. Новая область заменяет старые ожидающие запросы. Для миниатюр используются до восьми задач изображений (с учётом числа ядер) и две задачи видео. Экранные фото ограничены двумя задачами; прогнозируемый объём их текстур дополнительно ограничивает запуск соседних задач. Один слот изображений сохраняется для срочного запроса. Запись миниатюр выполняется отдельно, одним потоком с максимум восемью ожидающими изображениями.

По умолчанию кэш миниатюр занимает до 384 МиБ, кэш готовых фотографий до 1 ГиБ. Бюджет фото меняется в Settings. При memory pressure бюджеты снижаются, фон ограничивается; после сигнала normal заданные бюджеты восстанавливаются. Это лимиты управляемых кэшей, не строгий предел RSS процесса: исходные декодеры и выполняющиеся операции также занимают память.

Предзагрузка фото: до восьми соседей вперёд и трёх назад. При просмотре видео очередь фото очищается. Анимация готовится небольшим потоком, все её кадры в RAM не складываются. Дисковый кэш имеет лимит 30 ГиБ и вытеснение старых записей. Касания дискового кэша записываются в SQLite пакетами. Миниатюры выбираются в разрешении 256/512 px по размеру плитки.

Оригиналы размером более 100 мегапикселей отклоняются до подготовки текстур. Обычный показ готовит изображение до 2560/4096 пикселей по длинной стороне, масштабирование — до 8192. Поэтому режим 1:1 для источников крупнее этого предела не является полноразмерным просмотром оригинала. RAW, полноценный HDR и тайловая загрузка огромных изображений отложены.

Файлы кэша и каталог: `~/Library/Caches/local.mzera.mac`. Настройки: macOS UserDefaults для `local.mzera.mac`. Приложение не использует сеть; FFmpeg ограничен протоколом `file`.

## Сборка и проверки

Нужны Xcode с Metal Toolchain, Python 3 для упаковки, Homebrew FFmpeg 9 и libwebp (`brew install ffmpeg webp`). Пакет настроен на `/opt/homebrew/opt/ffmpeg` и `/opt/homebrew/opt/webp`. Debug-сборка включает полную диагностику конкурентности Swift; предупреждения миграции на Swift 6 перечислены в отчёте ревью.

```sh
# Если компонент Metal ещё не установлен:
xcodebuild -downloadComponent MetalToolchain

swift test
scripts/build-app.sh
```

Скрипт копирует транзитивные динамические библиотеки в `.app`, меняет install names на `@rpath`, подписывает локальные копии и проверяет подпись. Исходные Homebrew-библиотеки не изменяются.

Диагностика без окна:

```sh
.build/release/Mzera --diagnose "$HOME/Pictures"
.build/release/Mzera --probe-video /absolute/path/clip.webm
.build/release/Mzera --probe-animation /absolute/path/animation.webp
```

Необязательные метрики окна:

```sh
open dist/Mzera.app --args --folder /absolute/path/folder --metrics /absolute/path/metrics.json
```

Метрики включают интервал от обработчика перехода к уведомлению Metal о показе кадра. Это не измерение задержки физической клавиатуры. Сохраняются только времена, счётчики и расходы кэша, без имён файлов.

Архитектура описана в `docs/architecture.md`, результаты проверок — в `docs/verification.md`.

Версия 0.2.0: [разбор ревью и проверенные изменения](docs/review-response-2026-09-05.md). Натуральная сортировка использует стабильные ключи, не зависит от локали и может отличаться от порядка Finder. Неизменённый снимок после сканирования не пересортировывается и не сохраняется повторно.
