# Mzera for Mac

Минималистичный просмотрщик локальных изображений и коротких видео для Apple Silicon. Swift, AppKit, собственная Metal-сетка, Image I/O и FFmpeg / VideoToolbox. Исходная Linux-версия находится в отдельном репозитории `vdmkotai/mzera`.

## Запуск

Готовое приложение: `dist/Mzera.app`. Сборка содержит необходимые видеобиблиотеки и заранее скомпилированные Metal-шейдеры. Для запуска Homebrew не нужен.

Текущая сборка требует Apple Silicon и macOS 26 или новее. Требование macOS 26 связано в том числе с используемой сборкой FFmpeg. Проверена на M5 Pro с 64 ГБ RAM. Подпись локальная ad hoc; публикации и notarization нет.

```sh
open dist/Mzera.app
open dist/Mzera.app --args --folder "$HOME/Pictures"
```

При обычном запуске восстанавливаются папка, выбранный файл, режим и положение галереи. Приложение читает оригиналы и не предоставляет удаления, переименования или редактирования.

Папку можно перетащить из Finder в любую часть содержимого окна: сетку, просмотрщик, панель управления или строку состояния. Принимается одна локальная папка за раз. Она открывается тем же фоновым загрузчиком, что и через Open; файлы не копируются и не перемещаются. Курсор с плюсом означает, что папку можно отпустить.

## Возможности

- Рекурсивный обход, включая содержимое пакетов `.app`. Символические ссылки не обходятся.
- Общая сетка и группировка по папкам с закреплёнными заголовками.
- Сортировки: папка/имя, имя, дата изменения, размер; фильтр фото/видео.
- JPEG, PNG, WebP, AVIF, GIF, HEIC/HEIF, TIFF, BMP, APNG, JXL через доступные системные декодеры. Поддержка конкретного профиля зависит от Image I/O.
- GIF и анимированный WebP воспроизводятся только в просмотрщике. В сетке все миниатюры статичны.
- WebM, MP4, MOV, MKV, AVI через FFmpeg. VideoToolbox используется при успешной аппаратной инициализации; доступен программный путь.
- Ролики запускаются без звука и повторяются. Звук включается кнопкой или клавишей M.
- Ручное листание, fit, масштабирование, перемещение картинки, полноэкранный режим. Автоматического слайдшоу нет.
- Постоянный каталог SQLite, дисковые миниатюры, сверка после файловых событий FSEvents.

## Управление

| Клавиша | Действие |
|---|---|
| ⌘O | Открыть папку |
| Enter / двойной клик | Открыть выбранный файл |
| Esc / ⌘G | Вернуться в галерею |
| Стрелки | Выбор или переход между файлами |
| Home / End, Page Up / Down | Перейти к краю или на страницу |
| F / ⌘F | Полноэкранный режим |
| 0 / 1 | Вписать / показать пиксели декодированного изображения 1:1 |
| Pinch / ⌘колесо | Изменить масштаб |
| Перетаскивание | Переместить увеличенное изображение |
| + / − | Изменить размер миниатюр |
| Space | Пауза анимации или видео |
| M | Включить/выключить звук |
| ⌘← / ⌘→ | Перемотать ролик на 5 секунд |
| ⌘R | Пересканировать папку |

При быстром удержании стрелки позиция учитывает все нажатия, а экран показывает актуальное состояние. Обязательного показа каждого промежуточного файла нет.

## Ограничение работы и памяти

В очереди находятся только видимая область и небольшой запас. Новая область заменяет старые ожидающие запросы. Уже выполняющиеся декодирования ограничены: до четырёх фото и одна видеоминиатюра. Один слот фото сохраняется для срочного запроса. Запись миниатюр выполняется отдельно, одним потоком с максимум восемью ожидающими изображениями.

По умолчанию кэш миниатюр занимает до 384 МиБ, кэш готовых фотографий до 1 ГиБ. Бюджет фото меняется в Settings. При memory pressure бюджеты снижаются. Это лимиты управляемых кэшей, не строгий предел RSS процесса: исходные декодеры и выполняющиеся операции также занимают память.

Предзагрузка фото: до восьми соседей вперёд и трёх назад. При просмотре видео очередь фото очищается. Анимация готовится небольшим потоком, все её кадры в RAM не складываются. Дисковый кэш имеет лимит 30 ГиБ и вытеснение старых записей.

Оригиналы размером более 100 мегапикселей отклоняются до подготовки текстур. Обычный показ готовит изображение до 2560/4096 пикселей по длинной стороне, масштабирование — до 8192. Поэтому режим 1:1 для источников крупнее этого предела не является полноразмерным просмотром оригинала. RAW, полноценный HDR и тайловая загрузка огромных изображений отложены.

Файлы кэша и каталог: `~/Library/Caches/local.mzera.mac`. Настройки: macOS UserDefaults для `local.mzera.mac`. Приложение не использует сеть; FFmpeg ограничен протоколом `file`.

## Сборка и проверки

Нужны Xcode с Metal Toolchain, Python 3 для упаковки и Homebrew FFmpeg 9. Текущий пакет настроен на `/opt/homebrew/opt/ffmpeg`.

```sh
# Если компонент Metal ещё не установлен:
xcodebuild -downloadComponent MetalToolchain

swift test
scripts/build-app.sh
```

Скрипт копирует транзитивные динамические библиотеки в `.app`, меняет install names на `@rpath`, подписывает локальные копии и проверяет подпись. Исходные Homebrew-библиотеки не изменяются.

Диагностика без окна:

```sh
.build/release/Mzera --diagnose "$HOME/Pictures"
.build/release/Mzera --probe-video /absolute/path/clip.webm
```

Необязательные метрики окна:

```sh
open dist/Mzera.app --args --folder /absolute/path/folder --metrics /absolute/path/metrics.json
```

Метрики включают интервал от обработчика перехода к уведомлению Metal о показе кадра. Это не измерение задержки физической клавиатуры. Сохраняются только времена, счётчики и расходы кэша, без имён файлов.

Архитектура описана в `docs/architecture.md`, результаты проверок — в `docs/verification.md`.
